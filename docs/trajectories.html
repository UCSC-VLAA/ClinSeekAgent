Trajectory Examples

ClinSeekAgent rollouts over the 22-tool space (16 EHR + 6 image): the agent is given only a patient and a prediction time, then decides what to retrieve and when to answer. The agent sees only records available before the prediction time.

Only the agent's actions are shown (reasoning, tool calls, final answer). Tool responses are hidden because they contain credentialed clinical records, and each is replaced by a one-line structural summary; full outputs for credentialed users are in the gated dataset UCSC-VLAA/ClinSeek-Evaluation-Results.
